# Config Backup & Restore

Config Backup & Restore securely stores snapshots of your account configuration, allowing you to quickly recover from mistakes, device loss, account migration, accidental deletions, or failed configuration changes.

Your backups are stored securely on our servers with encrypted sensitive credentials.

### Why Use Config Backup & Restore?

Many users spend weeks or months building complex forwarding systems.

A single mistake can result in:

* Lost tasks
* Deleted filters
* Missing API keys
* Broken forwarding workflows
* Lost platform integrations
* Hours of manual reconfiguration

Config Backup & Restore provides a safety net that allows you to restore your setup within minutes.

### Features

#### Automatic Daily Backups

The system automatically creates configuration snapshots every day.

This ensures you always have recent recovery points available without any manual action.

Backups run automatically in the background and include your latest configuration changes.

Benefits:

* No manual exports required
* Continuous protection
* Always have recent restore points available

***

#### On-Change Protection Snapshots

Before potentially risky configuration changes, the system can automatically create a snapshot of your current setup.

Examples:

* Large task modifications
* Bulk task imports
* Filter restructuring
* Account changes
* Platform configuration updates

If something goes wrong, you can quickly roll back to the previous working configuration.

***

#### Preview Before Restore

Review backup details before restoring.

Preview information may include:

* Backup creation date
* Number of tasks
* Configured filters
* Connected accounts
* System settings
* Backup notes and metadata

This helps ensure you restore the correct version.

***

#### One-Click Restore

Restore a previous configuration snapshot with minimal effort.

Typical recovery scenarios:

* Accidental task deletion
* Misconfigured filters
* Broken automation workflows
* Lost settings after device changes
* Recovery from user mistakes

Instead of rebuilding everything manually, simply restore a previous snapshot.

***

#### Cross-Account Recovery

In special situations, administrators can assist with restoring backups to another account using a verified User ID.

Useful when:

* Migrating to a new account
* Recovering access after account loss
* Moving configurations between business accounts
* Disaster recovery situations

For security reasons, recovery requests may require account ownership verification.

***

#### Secure Credential Storage

Sensitive credentials are protected using encrypted server-side storage.

Protected data may include:

* API Keys
* Bot Tokens
* Platform Credentials
* Integration Secrets
* Automation Settings

Your backup data is never stored as plain text.

***

#### Server-Side Snapshots

Backups are stored securely on our infrastructure.

Benefits:

* No local storage required
* Accessible from any device
* Safe from device failures
* Available even after reinstalling the application

### Frequently Asked Questions

#### Do I need to create backups manually?

No. Backups are created automatically.

***

#### Are my API keys included?

Yes. Sensitive credentials are backed up securely using encrypted storage.

***

#### Can I restore an older version?

Yes. Available snapshots can be reviewed and restored individually.

***

#### Can I move my configuration to another account?

Yes. Administrator-assisted recovery is available for verified account owners.

***

#### Does restoring overwrite my current configuration?

Yes. Restoring a backup replaces the current configuration with the selected snapshot. We recommend reviewing the backup preview before proceeding.
