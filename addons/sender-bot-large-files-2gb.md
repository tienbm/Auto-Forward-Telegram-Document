# Sender Bot Large Files 2GB

## Sender Bot Large Files 2GB

### Overview

By default, Telegram Bot API sender bots have a **20MB file download limit** in Auto Forward.

The **Sender Bot Large Files 2GB** add-on removes this limitation from your Auto Forward workflow, allowing your sender bot to forward files **up to 2GB**.

This is useful for forwarding large videos, documents, audio files, and other media while continuing to use your configured Sender Bot.

> **File size limit:** Up to **2GB (2000MB)**\
> **Standard limit without add-on:** **20MB**

***

### Key Features

#### 📦 Forward Files Up to 2GB

Increase the Sender Bot file limit from **20MB to 2GB**, allowing much larger Telegram media and documents to be processed.

#### ⚡ Optimized Delivery

Small files continue to use the **faster standard delivery path**.

The large-file processing path is only used when necessary, helping maintain good forwarding performance for regular messages.

#### 🤖 Works With Sender Bot

The add-on extends your existing **Sender Bot** functionality. You don't need to replace your sender bot or create a separate forwarding setup.

***

### Supported Content

The add-on supports large files for:

* Photos
* Videos
* Documents
* Audio
* Voice messages
* Animations
* Video notes

***

### How It Works

Without the add-on:

**Telegram Source → Auto Forward → Sender Bot → Maximum 20MB**

With **Sender Bot Large Files 2GB**:

**Telegram Source → Auto Forward → Sender Bot → Maximum 2GB**

When Auto Forward processes a file, it determines the appropriate delivery path based on its size.

Files within the standard limit continue using the normal fast delivery path, while larger supported files can use the extended **2GB capability** provided by the add-on.

***

### How to Enable

1. Open **Auto Forward**.
2. Go to the **Add-ons** section.
3. Find **Sender Bot Large Files 2GB**.
4. Purchase or activate the add-on.
5. Once active, the increased file-size limit is automatically available for Sender Bot forwarding.

No additional task configuration is required.

***

### Example

Suppose your source channel posts a **500MB video**.

Without the add-on, the Sender Bot cannot process the file because it exceeds the standard **20MB limit**.

With **Sender Bot Large Files 2GB** enabled:

**500MB Video → Auto Forward → Sender Bot → Target Channel ✅**

The same applies to other supported files up to **2GB**.

***

### Important Notes

* This add-on applies specifically to **Sender Bot file forwarding**.
* Maximum supported file size with the add-on is **2GB (2000MB)**.
* Files above 2GB are not covered by this add-on.
* Smaller files continue using the standard delivery path for better performance.
* The add-on is **SIMPLE**, so no per-task configuration is required.
* The add-on has a **30-day duration** according to the current configuration.

***

### When Should I Use This Add-on?

**Sender Bot Large Files 2GB** is recommended if your forwarding sources regularly contain:

📹 Large videos\
📁 Large documents or archives\
🎵 Large audio files\
🎙 Voice or other media files\
📦 Any supported files exceeding the standard **20MB Sender Bot limit**

If all of your forwarded files are below 20MB, you generally don't need this add-on.
