# Pinned Message Forwarding

### Price

**$2.99 for 30 days**

This add-on **does not renew automatically**. After 30 days, you can purchase it again if you want to continue using it.

### Before you start

* You need to have a forwarding task.
* Make sure the task has the correct **source chat(s)** and **destination(s)** selected.
* Your account must still have access to both the source and destination chats.

### Setup

1. Open your forwarding task.
2. Check that the correct **source chat(s)** and **destination(s)** are selected.
3. Open **Add-ons**.
4. Select **Pinned Message Forwarding**.

<figure><img src="../.gitbook/assets/image (291).png" alt=""><figcaption></figcaption></figure>

5. Purchase and enable the add-on.
6. Optional: Enable **Ignore messages sent by bots** if you do not want to forward messages originally posted by bots.

<figure><img src="../.gitbook/assets/image (292).png" alt=""><figcaption></figcaption></figure>

After it is enabled, the add-on starts monitoring pin actions in the selected source chats.

### How it works

* Only pin actions that happen **after the add-on is enabled** are processed.
* An older message is still forwarded if it is pinned after the add-on is enabled.
* Messages that were already pinned before the add-on was enabled are not sent automatically.
* Pinning the same message again does not create duplicate deliveries.

### Filtering messages posted by bots

The **Ignore messages sent by bots** option checks who **originally posted** the pinned message, not who performed the pin action.

For example, if a user pins a message posted by a bot, the message is still treated as bot-posted and is skipped when this option is enabled.

### After 30 days

The add-on is valid for 30 days and does not renew automatically. If you want to continue forwarding pinned messages after that period, purchase **Pinned Message Forwarding** again.

### Troubleshooting

If a pinned message is not forwarded, check the following:

1. **Pinned Message Forwarding** is enabled.
2. The task uses the correct **source chat(s)** and **destination(s)**.
3. The pin action happened after the add-on was enabled.
4. Your account still has access to both the source and destination chats.
5. If **Ignore messages sent by bots** is enabled, check whether the message was originally posted by a bot.

Remember that messages pinned before the add-on was enabled are not sent automatically.

### Frequently asked questions

#### Are older messages forwarded?

Yes. The age of the message does not matter; an older message is still forwarded if it is pinned after the add-on is enabled.

#### Are messages pinned before activation sent immediately?

No. The add-on only processes pin actions that happen after it is enabled.

#### Does the bot filter check who pinned the message or who posted it?

The filter checks who originally posted the message, not who performed the pin action.

#### Does the add-on renew automatically?

No. The add-on costs **$2.99 for 30 days**; you must purchase it again if you want to continue using it after that period.
