**Crypto Mode: Automatic Filtering of Tokens and Contract Addresses**

Enhance your message filtering by automatically forwarding relevant content about tokens and contract addresses.

{% embed url="https://youtu.be/XSLx4O8tmTA" %}

&#x20;✅ **Crypto Mode Features:**

* **Contract Address Filtering:** Detects across multiple blockchains (e.g., BTC, ETH).
* **Fast Mode:** Increases filtering speed (disables editing/replies).
* **Contract Frequency Checker:** Analyzes contract appearance patterns.
* **Duplicate Detection:** Avoids repeated posts on the same contract.
* **Custom Header/Footer:** Adds context to forwarded messages.

⚙️ **Setup Guide**

1. **Navigate to Detail Task Forward**\
   Access the "Detail Task Forward" section.
2. **Select Crypto Mode**\
   Choose the desired crypto mode.
3. **Configure Parameters**\
   Set the required parameters according to your needs.
4. **Save**\
   Remember to save your configurations.

### Network Filter in Crypto Mode

**Network Filter** lets you choose which blockchain networks your Crypto task will process. It supports both Forward and Publish tasks, with six available networks: **Ethereum (ETH), BNB Smart Chain (BSC), Robinhood Chain, Base, Arbitrum One, and Solana**.

### How to use it

1. Open the task you want to configure and go to **Crypto Mode**.
2. Enable **Contract Address** to display the Crypto options.
3. Find **Network Filter** below **Duplicate Content Checking**.
4. Select one or more networks. Selected networks have a blue border and a checkmark. Tap a selected network again to deselect it.
5. Tap **Done** to save your settings.

### All networks or specific networks?

* **All networks:** keeps the default Crypto processing behavior without restricting it by network.
* **Specific networks:** only processes addresses with evidence identifying them as belonging to a selected network, such as a matching blockchain explorer link.

For example, select **Ethereum** and **Solana** to process only addresses identified as belonging to those two networks.

{% hint style="warning" %}
Selecting all six networks still requires evidence identifying the network, so it is different from All networks. An address on its own, or one with missing or conflicting network information, may be skipped.
{% endhint %}

### Things to know

* Selecting **All networks** clears individual selections. Deselecting the last network also returns the filter to All networks. Tap **Done** to save the change.
* Turning off Crypto hides Network Filter but keeps your saved selection for the next time you enable it.
* The feature uses your existing Crypto eligibility. No separate network filter purchase is required.
* If saving fails, check the error message and your connection. Your unconfirmed selections remain on the screen so you can continue editing.
